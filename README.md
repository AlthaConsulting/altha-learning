ALTHA LEARNING
Portal pembelajaran internal Altha Consulting
Versi 3.0

FITUR PORTAL
  Beranda        Penjelasan portal, ringkasan, dan dasbor pribadi setelah
                 nama dipilih: cincin kemajuan, lansiran tenggat, dan
                 kartu lanjutkan belajar.
  Katalog        15 program di 4 praktik, dengan pencarian bebas dan
                 penyaring praktik serta tingkat.
  Raport         Empat tab: Ringkasan, Modul, Riwayat, dan Sertifikasi.
                 Dilengkapi ekspor CSV per konsultan.
  Tim            Matriks kepatuhan seluruh konsultan untuk L&D dan atasan,
                 dengan ekspor CSV.

ISI PAKET
  17 berkas HTML, 700 KB
  1  portal          Altha-Learning.html
  2  simulasi ujian  CDMP-Set-01.html, CDMP-Set-02.html
  14 deck flashcard  CDMP-Flashcards-Ch1 sampai Ch14

CARA MEMASANG
  1. Salin SELURUH berkas ke satu direktori yang sama di web server intranet.
  2. Arahkan pengguna ke Altha-Learning.html sebagai titik masuk.
  3. Selesai.

CATATAN UNTUK TIM IT
  Seluruh berkas bersifat mandiri. Tidak ada permintaan ke internet,
  tidak ada basis data, tidak ada dependensi server, dan tidak ada cookie.

  Kemajuan belajar disimpan memakai localStorage peramban. Artinya
  catatan melekat pada perangkat dan peramban, bukan pada akun pengguna.
  Konsultan yang berpindah perangkat memulai dari nol. Portal tetap
  berjalan bila localStorage diblokir, dengan peringatan di halaman
  Raport bahwa kemajuan tidak akan tersimpan.

  Nama berkas jangan diubah. Portal memanggil tiap modul dengan nama
  persis seperti tertulis di atas.

  Cukup dilayani sebagai berkas statis. Web server apa pun memadai.
  Peramban yang didukung: versi terbaru Chrome, Edge, Firefox, dan Safari.

YANG HARUS DIISI L&D SEBELUM DIUMUMKAN
  1. Blok ROSTER di dalam Altha-Learning.html. Cari kata ROSTER dan
     ganti daftar karyawan serta penugasannya dengan data sebenarnya.
     Selama masih berisi contoh, halaman Raport menampilkan peringatan.
  2. Empat isian bertanda kuning di halaman program: pemilik program,
     PIC pendaftaran, biaya dan reimbursement, serta batch berikutnya.
  3. Dua isian bertanda kuning di footer: pemilik portal dan tanggal
     peninjauan berikutnya.
