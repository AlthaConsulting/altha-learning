CARA MEMASANG
  1. Salin SELURUH berkas ke satu direktori yang sama di web server intranet.
  2. Arahkan pengguna ke Altha-Learning.html sebagai titik masuk.
  3. Selesai.

CATATAN UNTUK TIM IT
  Seluruh berkas bersifat mandiri. Tidak ada permintaan ke internet,
  tidak ada basis data, tidak ada dependensi server, tidak ada cookie,
  dan tidak ada penyimpanan di peramban.

  Nama berkas jangan diubah. Portal memanggil tiap modul dengan nama
  persis seperti tertulis di atas.

  Cukup dilayani sebagai berkas statis. Web server apa pun memadai.
  Peramban yang didukung: versi terbaru Chrome, Edge, Firefox, dan Safari.

SEBELUM DIUMUMKAN
  Lima isian di portal sengaja dikosongkan dan ditandai "diisi oleh L&D":
  pemilik program, PIC pendaftaran, biaya dan reimbursement, batch
  berikutnya, serta tanggal peninjauan berikutnya.

SUMBER MATERI
  Disusun dari DAMA-DMBOK2. Materi latihan mandiri, bukan materi resmi
  DAMA International, dan tidak berafiliasi dengan DAMA.
